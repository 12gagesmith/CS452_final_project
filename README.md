# Gage Smith's CS 452 Final Project

## Description

I want to build a more interactive map of campus that allows you to put in places and it will create a route for you, both indoor and outdoor. You will be able to add more than two points and plan out a route through your entire day, which will get saved. All a user has to do is enter either a building/room number (e.g., JKB 3106) as a point or the name of an outdoor area (e.g., Brigham Square). Another option I may implement is adding categories of places that a user can search for, such as study spaces or restrooms. I might come up with more features as I continue to work on this project.
